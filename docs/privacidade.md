# Privacidade, segurança e publicação

Este repositório apresenta apenas o conceito técnico do assistente. **Não inserir exports operacionais de n8n, mesmo que pareçam conter credenciais ocultas.**

## Conteúdo proibido neste portfólio

- Chaves, tokens, senhas, IDs de credenciais, números de telefone, CPFs ou dados de participantes.
- Identificadores reais de webhook, planilhas, bancos e sessões.
- URLs internas, links privados, prompts completos e tabelas de preços/recebimentos operacionais.
- Conversas, comprovantes de transferência, imagens de pessoas, áudio ou conteúdo de execução real.
- Arquivos de export com dados de teste fixados (**pinData**) ou propriedades internas copiadas sem revisão.

## Publicação segura

1. Obter autorização para divulgar o projeto na forma proposta.
2. Publicar somente explicações genéricas e **exemplos criados do zero**.
3. Fazer inspeção de conteúdo e histórico Git antes de adicionar arquivos.
4. Se uma credencial for publicada por engano, revogá-la e substituí-la imediatamente; remover o arquivo depois não basta.
5. Não reproduzir uma identidade visual ou material original sem permissão.
